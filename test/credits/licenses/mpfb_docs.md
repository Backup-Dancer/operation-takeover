MPFB
MPFB is a free and open source human character generator for blender. For a general introduction
to what MPFB is, see About MPFB . For more in-depth documentation, such
as a getting started guide, see the documentation .
Or if you prefer video for a general introduction, there is a
MPFB Tutorial: Installation and Getting Started video on youtube.
For frequently asked questions, see the FAQ .
To download MPFB2, see the MPFB Downloads page.
The release notes of the latest release are available in release notes for 2.0.15 .
There are also preliminary release notes for the next upcoming release available.
For various tutorial videos, see the Youtube channel .
For an overview of what is planned for MPFB in the nearest future, see the roadmap .
If you enjoy MPFB and want to help evolve it, there is also a contributing to MPFB page.
